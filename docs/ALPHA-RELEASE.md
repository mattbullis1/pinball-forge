# PINBALL FORGE v0.7.0-alpha.1

Initial public alpha, November 11, 2026.

- Reference-style construction workbench with the approved header, headboard and tool/color column.
- Move individual wall points; use Stretch to add points and Box to create independent wall loops.
- Background/headboard pictures, artwork, project save/import/export and standalone HTML5 game export.
- Three-ball catcher releases balls downward under gravity; bumpers and lights have pinball sounds.
- Mouse, keyboard and touch flippers, with independent simultaneous input.

Validation: 156 tests across 13 files; TypeScript/production build; editor and standalone browser checks. Physical tablet speaker playback has not been verified. This is a prerelease, not a final stable release.

Source: https://github.com/mattbullis1/pinball-forge

Live construction set: https://pinball.mattbullis.com/

The static-site release ZIP contains the built editor. Extract it into a static web server directory, preserving all files and relative paths. It requires no server-side application or database. Individual playable tables are exported from the editor using DOWNLOAD MY PINBALL GAME.

Browser saves are local to the current device and origin. Download an editable project file to back up or transfer a table.

See LICENSES.md and ASSET-NOTICE.txt for the distinction between MIT application code and the supplied classic reference artwork.
